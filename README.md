# 🚑 RescueNet

RescueNet is an emergency hospital resource allocation and routing system designed to help manage accident cases by identifying suitable hospitals, checking available resources, calculating routes, and recommending an appropriate hospital.

## Features

- Emergency case management
- Hospital resource monitoring
- ICU availability
- Cardiology availability
- Emergency department availability
- Hospital requirement matching
- Shortest-route calculation
- Dijkstra's shortest path algorithm
- Graph-based road network
- Min Heap
- Priority Queue
- Hospital ranking
- Resource allocation
- Allocation confirmation
- Audit logging
- Hospital dashboard
- Interactive route network

## DSA Used
